# Event Service

## Технологии

- **Язык программирования:** C#
- **Платформа:** .NET 9
- **Backend:** ASP.NET Core
- **Межсервисное взаимодействие:** gRPC (Protocol Buffers)
- **Асинхронные события:** Apache Kafka
- **ORM:** Entity Framework Core
- **База данных:** PostgreSQL
- **Архитектура:** Microservices, Event-Driven Architecture
- **Контейнеризация:** Docker
- **Инструменты:** Git, Swagger/OpenAPI, Postman

---

## Описание сервиса

**Event Service** — микросервис в составе распределённой системы покупки и бронирования билетов на мероприятия.  
Сервис отвечает за управление мероприятиями, площадками проведения и схемами залов, а также за валидацию доступности мест при бронировании.

Event Service не реализует бизнес-логику бронирования или оплаты, а предоставляет достоверные данные и проверки другим сервисам системы через gRPC и Kafka, следуя принципам разделения ответственности и eventual consistency.

---

## Функциональные возможности

### Управление мероприятиями
- Создание и редактирование мероприятий
- Хранение информации об организаторе мероприятия
- Контроль прав доступа:
  - организатор может редактировать только созданные им мероприятия
  - администратор имеет полный доступ

### Управление площадками и залами
- Создание и редактирование площадок проведения мероприятий
- Управление схемами залов
- Хранение информации о местах (ряды, номера)

### Работа с местами
- Предоставление схемы зала по запросу
- Валидация доступности мест при бронировании
- Отметка проданных мест
- Предотвращение конфликтов при параллельных бронированиях

## Взаимодействие с другими сервисами

### gRPC
Event Service предоставляет gRPC-интерфейсы для:
- получения информации о мероприятиях
- получения схемы зала
- проверки доступности мест при бронировании

Основные потребители:
- **Ticket Service**
- **Payment Service**
- **HTTP Gateway**

### Kafka
Event Service публикует доменные события в Kafka:
- событие о создании мероприятия
- события об изменении заполненности зала

Данные события используются:
- **Analytic Service** — для формирования статистики по мероприятиям
- **другими сервисами** для асинхронной обработки бизнес-сценариев

---

## Роль сервиса в системе

Event Service является источником истины для:
- мероприятий
- площадок
- схем залов
- состояния мест

Сервис спроектирован как независимый компонент, готовый к горизонтальному масштабированию и отказоустойчивому развертыванию в микросервисной среде.
